## Cursor Cloud specific instructions

Static site: `index.html`, `howto.html`, `privacy_policy.html`. No build step, no dependencies, no tests.

- Run locally by serving the repo root with any static server, e.g. `python3 -m http.server 8082`, then open the printed URL.
- There is nothing to install; the startup update script intentionally does nothing for this repo.
